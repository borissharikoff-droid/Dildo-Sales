# CLAUDE.md — Boostyfi LK Upsell Modals Prototype

## Что это

Кликабельный self-contained HTML-прототип системы модальных окон для личного
кабинета **boostyfi.com**. Один файл `survey-mockup.html` — открывается в
браузере без сервера, без зависимостей. Используется как наглядное ТЗ для
фронтенд-команды перед интеграцией в боевой ЛК.

Здесь **нет бэкенда, API, сборки** — только HTML + inline CSS + inline JS.
Не предлагать перевод на React/Next/любой фреймворк без явной просьбы.

## Архитектура

При каждом «входе в ЛК» показывается **стек из 3 модалок подряд** (карусель
с точками-пейджером сверху):

1. **Card 1 — Opinion poll** — мягкий сбор мнения: «нравится ли это», «что
   ближе», NPS-варианты. Цель — юзер чувствует, что его слушают.
2. **Card 2 — Ecosystem stats** — сводные цифры платформы, рост проектов,
   календарь раундов. Цель — показать, что Boostyfi растёт.
3. **Card 3 — Personal offer** — конкретный оффер по сегменту + карточка
   менеджера + pre-filled сообщение + кнопка `t.me/share/url` с готовым
   текстом. Цель — толкнуть на сделку через сейлза.

Пропуск любой карточки (тусклый крестик ✕ в углу) — переход к следующей.
На третьей крестик закрывает весь стек. `localStorage.boostyfi_modal_done`
блокирует повторный показ; кнопка `↻ Показать стек` сбрасывает флаг.

## Сегментация

В demo-баре сверху — 5 контролов:

- **Имя** — подставляется в заголовки и pre-filled сообщение
- **Стример** — Phil / Brad / Нет. Влияет только на палитру и ветку
  менеджера (Михаил для Phil, Алексей для Brad). **Не на тексты офферов.**
- **Объём** — $5k / $25k / $50k / $100k / **$500k+ (Whale)**. Это главное.
- **Рефералы** — до 5 / до 20 / 20+. Может включать реф-оффер.
- **Диверсификация** — состав уже купленного: «по чуть-чуть» / 1 продукт /
  2 продукта / все кроме одного. Влияет на офферы (например,
  «закрой коллекцию» для `all-but-one`).

Tier-функция `tierOf(volume)` возвращает: `starter` / `mid` / `high` / `whale`.

## Whale-tier ($500k+) — Black Tier

Чёрный премиум-стиль (а-ля Amex Black):
- Палитра баннера: `#000 → #101010`, акцент champagne-gold `#d4af37`
- Eyebrow: `VIP · BLACK TIER · PRIVATE`
- Тонкая золотая обводка вокруг модалки + мягкое золотое свечение
- Имя пользователя прямо в заголовке («Boris, ваш персональный слот готов»)
- Персональный менеджер по имени (Михаил/Алексей)
- Pre-filled сообщение от первого лица менеджера
- Офферы $99k–$180k (Private placement, Marsh Legends Studio Pack)

Для остальных tier-ов — оранжево-красный стиль Boostyfi.

## Пулы вопросов и статов

Чтобы юзер видел разное при каждом входе, вопросы и статы **рандомизируются**:

- `QUESTION_POOLS.general` — 9 вопросов для не-китов
- `QUESTION_POOLS.whale` — 6 вопросов для китов (private allocation,
  Marsh Legends, VIP-перки)
- `STAT_POOLS` — 4 набора цифр (раунды на старте / экосистема / календарь
  дропов / Marsh Legends)

Рандом срабатывает в `openStack()` и в кнопке `🎲 Перемешать пул`.

## Логика подбора оффера

`pickOffer(segment, tier)` — детерминированная функция, выбирает оффер по
комбинации tier × div × refs × streamer. Базовые случаи:

- starter + 1 продукт → «Добери JGGL в текущем раунде» ($89 вместо $129)
- starter + 2 продукта → «Зайди в Arteki по early-phase» ($99)
- mid + 1 продукт → Diversify Pack (TPC + IMBA Card) — $690
- high + all-but-one → «Заверши коллекцию» — IMBA × 10 + TPC, $13.5k
- whale + all-but-one → Private TPC Marsh Legends — $180k
- whale + 1 продукт → Private 4-Project Pack — $165k

## Pre-filled Telegram message

В sales-карточке — редактируемая textarea с готовым сообщением. Кнопка
`✈️ Открыть чат в Telegram` ведёт на `t.me/share/url` с подставленным
текстом. В боевой версии это должен быть прямой `t.me/<username>`
конкретного менеджера (сейчас `t.me/share` для демо).
